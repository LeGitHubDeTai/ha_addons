# Deemix - Home Assistant Add-on

[Deemix](https://github.com/bambanah/deemix) auto-hébergé pour Home Assistant
(fork maintenu du projet de RemixDev) : recherchez et téléchargez titres,
albums, playlists et discographies depuis le catalogue Deezer (MP3 128/320, FLAC),
avec métadonnées complètes, via une interface web moderne accessible depuis
Home Assistant (Ingress).

- Web UI : `:6595` (Ingress recommandé)
- Dossiers : musique `/media/deemix`, config `/share/deemix`
- Compte Deezer requis (connexion via ARL dans l'interface web)

Voir [DOCS.md](./DOCS.md) pour la configuration détaillée.
